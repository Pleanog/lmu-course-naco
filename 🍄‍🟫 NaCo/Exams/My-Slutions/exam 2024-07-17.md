In **non-entangled** (a.k.a. **separable**) states, each qubit just has its own behavior, and the full state can be written as:
$$|\psi\rangle = |\phi\rangle \otimes |\chi\rangle$$
That is: **"the state of the whole system = qubit A’s state × qubit B’s state"**
If you _can_ write a state like that, it's **not entangled**. If you _can’t_, it's entangled.

A two-qubit quantum state is **not entangled** if it can be written as a **tensor product** of the two  individual states of qubits:
$$|b\rangle = (\alpha |0\rangle + \beta |1\rangle) \otimes (\gamma |0\rangle + \delta |1\rangle)$$
that can be also written as:

$$|b\rangle = \alpha\gamma |00\rangle + \alpha\delta |01\rangle + \beta\gamma |10\rangle + \beta\delta |11\rangle $$

Any not entangled state needs to have all (here four) permutations of states
